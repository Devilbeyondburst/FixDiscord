> Это средство перехвата и фильтрации трафика, без которого zapret не работает.
> Его могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует компоненты WinDivert как инструменты повышенного риска или хакерские средства. В результате файл удаляется и отправляется в карантин. В детекте обычно встречается название `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно умеете настраивать исключения, предпочтительнее добавить исключение. При отсутствии такой уверенности лучше отключить детектирование PUA.

## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 рекомендуется этот способ.
    * Владельцам роутеров Keenetic нужно активировать параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Получите zip- или rar-архив со [страницы последнего релиза](https://github.com/Devilbeyondburst/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять.

4. Распакуйте файлы в каталог, в пути к которому нет кириллических букв и специальных символов.

5. Запустите подходящий файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Чтобы включить автоматический запуск, выберите в **`service.bat`** пункт `Install Service`, затем нужную стратегию.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегий.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для себя**.

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из списка служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** — изменить режим обхода для игр и прочих сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Значение в скобках показывает, включён режим или выключен.
  - **`IPSet Filter`** — изменить режим обхода для ресурсов из `ipset-all.txt`.  
  Это может помочь при проверке ресурса, который без zapret открывается, а с ним — нет.  
  В скобках выводится текущее состояние:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP сверяется со списком
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений.
  - **`Replace active fakes`** — заменить текущий фейк другим файлом из каталога `bin`.
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>.
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В финале можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент.
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`.
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon.


## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, ознакомьтесь с [#522](https://github.com/Devilbeyondburst/zapret-discord-youtube/issues/522).

### Не удаётся подобрать стратегию
- Откройте командную строку с правами администратора.
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущая версия hosts устарела, программа предложит обновить файл вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - Откройте текстовый файл `hosts` в появившейся папке через редактор, запущенный от имени администратора.
  - Вставьте скопированные строки в конец `hosts` или замените ранее добавленный аналогичный блок.
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Работа этого способа не гарантируется. При неудаче используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Devilbeyondburst/tg-ws-proxy) либо с любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Работа стратегий со временем может прекращаться.**
> Стратегия способна действовать некоторое время, а затем перестать помогать после её обнаружения.
> Здесь собрано много вариантов обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте, нет ли ошибок.

- Убедитесь, что нужный адрес присутствует в доменных списках или среди IP.

- Проверьте остальные стратегии, в том числе **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация: [#765](https://github.com/Devilbeyondburst/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- В **`service.bat`** выберите `Remove Services`.
- Запустите `Run Diagnostics`; исправьте найденные ошибки и в конце подтвердите действие клавишей Y.
- Удалите старый каталог zapret.
- Загрузите свежую версию [со страницы релизов](https://github.com/Devilbeyondburst/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива через контекстное меню. Если внизу справа есть пункт разблокировки, включите его, нажмите «Применить», затем «ОК».
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы.
- Запускайте разные `general`-скрипты и проверяйте доступ к интернет-ресурсам. Если вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом zapret

- Проверьте в `service.bat`, что для `Game Filter` указано **`disabled`**, а для `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Инструкция размещена здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с теми же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Определите имя службы в командной строке Windows, открытой через Win+R → `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройки [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если рабочая стратегия перестала помогать, проверьте остальные варианты.
- Также смотрите [#251](https://github.com/Devilbeyondburst/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8F-использование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- Откройте `service.bat` → `Run Diagnostics` и очистите там кэш Discord.
- Проверьте Discord и определите, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно пользуйтесь ей.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- Дополнительно: [#252](https://github.com/Devilbeyondburst/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Devilbeyondburst/tg-ws-proxy).
- Другой вариант — использовать бесплатные MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учитывайте, что режим `ipset any` способен нарушить открытие множества сайтов. Не оставляйте его включённым постоянно: определите IP-адреса, которыми пользуется игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Devilbeyondburst/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Опишите её [здесь](https://github.com/Devilbeyondburst/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Дополнительные адреса можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены будут учтены автоматически.
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Например, когда сеть присутствует в `ipset-all.txt`, но конкретный домен фильтровать не требуется.
- **`ipset-all.txt`** — IP-адреса и подсети.
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые необходимо исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
